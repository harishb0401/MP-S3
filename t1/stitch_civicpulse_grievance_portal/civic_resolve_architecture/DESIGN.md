## Brand & Style

This design system serves a civic-scale infrastructure platform dedicated to grievance redressal, public accountability, and emergency municipal prioritization. The aesthetic blends institutional authority with human-centered digital efficiency.

### Visual Character
- **Institutional Authority:** Grounded, unshakeable, and transparent. The interface projects reliability, state-level durability, and official accountability without appearing bureaucratic, stagnant, or intimidating.
- **Accessible Utility:** Strict adherence to Universal Design and WCAG 2.2 AAA legibility benchmarks. Visual treatments never compromise scan speed, high-stress comprehension, or screen-reader parseability.
- **Design Movement:** Modern Institutionalism—combining structured grid discipline, crisp structural dividers, functional surface containment, and purpose-driven semantic status signaling.

## Colors

The color system operates on high-contrast chromatic disciplines designed to establish visual calm on dense administrative screens while ensuring urgent issues demand immediate eye focus.

### Palette Architecture
- **Primary Navy (`#0F2942`):** Primary actions, structural navigation, primary document headers, and high-emphasis focus rings.
- **Secondary Deep Navy (`#1B365D`):** Active navigation items, secondary actions, and metric callouts.
- **Surfaces & Canvases:**
  - Base Background: Pure Light Slate (`#F8FAFC`).
  - Container / Surface Elevated: Crisp White (`#FFFFFF`).
  - Recessed Workspaces & Table Headers: Slate Neutral (`#F1F5F9`).
- **Borders & Dividers:** Cool Slate (`#E2E8F0`) for soft boundaries; Darker Slate (`#CBD5E1`) for strict structural divides and focused input fields.

### Status & Priority Tiers
- **Resolved / Stable:** Forest Green (`#16A34A`), surface tint (`#DCFCE7`), text contrast (`#14532D`).
- **In-Progress / Pending:** Amber Orange (`#D97706`), surface tint (`#FEF3C7`), text contrast (`#78350F`).
- **Urgent / High-Priority / Escalated:** Crimson Red (`#DC2626`), surface tint (`#FEE2E2`), text contrast (`#7F1D1D`).
- **Information / System Notice:** Slate Blue (`#2563EB`), surface tint (`#DBEAFE`), text contrast (`#1E3A8A`).

## Typography

The design system relies entirely on **Public Sans**, an open-source, government-grade typeface engineered specifically for public sector applications, legal documents, and digital portals.

### Application Guidelines
- **Case Numbers & Tracking IDs:** Rendered in `data-mono` using tabular numbers (`font-variant-numeric: tabular-nums`) to preserve spatial alignment in dense lists.
- **Labels & System Chips:** `label-sm` utilizes subtle letter-spacing for instantaneous identification at arm's length or on mobile field displays.
- **Readability Rules:** Line-length for grievance detail bodies is capped at 72 characters (`max-w-prose`) to avoid visual fatigue during long triage sessions.

## Layout & Spacing

A structured fluid layout model guarantees that density and legibility remain balanced whether accessed by citizens on mobile phones or desk operators running dual-monitor dashboards.

### Grid & Breakpoints
- **Desktop (≥ 1280px):** 12-column grid system, fixed 280px left rail for system navigation, 32px canvas margins, and 24px column gutters. Main content area capped at 1600px width.
- **Tablet (768px – 1279px):** 8-column layout, collapsable drawer navigation, 24px canvas margins, and 16px gutters.
- **Mobile (< 768px):** 4-column layout, bottom app bar or sticky top header, 16px margins, and 12px gutters.

### Spacing Philosophy
- Use `space-xs` (4px) and `space-sm` (8px) for tightly coupled visual units (icon + text, badge padding, form label to input).
- Use `space-md` (16px) for interior card padding, table row heights, and standard vertical stacks.
- Use `space-lg` (24px) to separate functional modules within cards and form sections.
- Use `space-xl` (32px) for page section separators, table-to-analytics transitions, and modal padding.

## Elevation & Depth

To avoid optical noise in data-heavy environments, depth relies on low-contrast outlines and soft, institutional ambient shadows.

### Layering Archetypes
- **Level 0 (Surface Base):** `#F8FAFC`. Background canvas, non-interactive regions.
- **Level 1 (Card / Table Surface):** `#FFFFFF` with a 1px border (`#E2E8F0`). Shadow: `0 1px 3px 0 rgba(15, 41, 66, 0.04), 0 1px 2px -1px rgba(15, 41, 66, 0.03)`.
- **Level 2 (Interactive Floating / Active Rows):** `#FFFFFF` with border (`#CBD5E1`). Shadow: `0 4px 6px -1px rgba(15, 41, 66, 0.06), 0 2px 4px -2px rgba(15, 41, 66, 0.04)`.
- **Level 3 (Flyouts, Menus, Drawers, Priority Modals):** `#FFFFFF` with border (`#E2E8F0`). Shadow: `0 10px 15px -3px rgba(15, 41, 66, 0.08), 0 4px 6px -4px rgba(15, 41, 66, 0.03)`.

Overlay modals must use a solid structural backdrop: `rgba(15, 41, 66, 0.60)` with a subtle `backdrop-filter: blur(2px)` to maintain environmental grounding.

## Shapes

The design uses balanced, modern geometric radii (Token `2`), balancing human approachability with structural order.

### Metric Rules
- Standard containers, form fields, and buttons use `rounded-md` (`0.5rem` / 8px).
- Large dashboard cards, data panels, and multi-step complaint forms use `rounded-lg` (`1rem` / 16px).
- Floating action containers, system notices, and notification alerts use `rounded-xl` (`1.5rem` / 24px).
- Badges, priority tags, avatar placeholders, and counter indicators use pill radius (`9999px`).

## Components

### Buttons
- **Primary:** Background `#0F2942`, text `#FFFFFF`, border none, hover `#1B365D`. Focus: 2px offset with 2px ring `#0F2942`.
- **Secondary:** Background `#FFFFFF`, text `#0F2942`, 1px border `#CBD5E1`, hover `#F1F5F9`.
- **Urgent Resolution Action:** Background `#DC2626`, text `#FFFFFF`, hover `#B91C1C`. Focus ring `#DC2626`.
- **Ghost:** Text `#334155`, hover background `#F1F5F9`.

### Chips & Badges
- Pill-shaped (`rounded-full`), padding `0.25rem 0.75rem`, text `label-sm`.
- **Resolved:** Background `#DCFCE7`, border `#BBF7D0`, text `#14532D`.
- **In-Progress:** Background `#FEF3C7`, border `#FDE68A`, text `#78350F`.
- **High-Priority / Urgent:** Background `#FEE2E2`, border `#FECACA`, text `#7F1D1D`. Includes a 6px solid `#DC2626` status dot indicator.

### Input Fields & Controls
- Standard height: 42px (mobile 46px for touch targets).
- Background `#FFFFFF`, border 1px `#CBD5E1`, radius `0.5rem`, text `body-md`.
- Active/Focused: Border 1.5px `#0F2942`, ring 3px `rgba(15, 41, 66, 0.15)`.
- Error state: Border 1.5px `#DC2626`, ring 3px `rgba(220, 38, 38, 0.15)`. Helper text in `body-sm` `#DC2626`.

### Data Tables & Ticket Lists
- Header: Background `#F1F5F9`, 1px border-bottom `#CBD5E1`, text uppercase `label-md` `#475569`.
- Rows: Background `#FFFFFF`, border-bottom 1px `#E2E8F0`, hover state `#F8FAFC`.
- High-priority rows feature an inset 4px solid Crimson Red (`#DC2626`) left border.
- Integrated quick-action triggers (Escalate, Reassign, Close) revealed on hover or pinned to table cell right.

### Grievance Detail Card
- Background `#FFFFFF`, border 1px `#E2E8F0`, corner radius `1rem`.
- Header section houses ticket ID, filing timestamp, citizen verification indicator, and current SLA countdown timer.
- Audit trail utilizes a structured vertical timeline with 2px connecting lines (`#E2E8F0`) and state-colored checkpoint nodes.
